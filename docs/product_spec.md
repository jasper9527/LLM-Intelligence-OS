# Product Spec

## Goal

Build a top-down, maintainable LLM intelligence system that runs well in a Codex cloud environment and publishes static HTML for cross-device reading.

## Non-goals

The system must not become a personal execution workspace. It excludes learning plans, pilot backlogs, application shortlists, interview reminders, and weekly personal action plans.

## Operating principles

- Preserve breadth before premature scoring.
- Separate evidence collection, routing, synthesis, and presentation.
- Keep decision-making outside the system.
- Include negative signals, controversies, and breakout signals by design.
- Let weekly briefs act as navigation, not as a dumping ground.
